My Meshes · ADR-0002 · UI framework and visual direction

Four looks for the same library screen

Each mockup renders the identical screen: sidebar with library views, smart collections and the folder tree; tabs; a filterable thumbnail grid; the project inspector; a sync status bar. Same markup, same data, only the CSS differs, so what you are comparing is treatment and the component library that produces it with the least fighting. Every mockup has a light/dark toggle (half-circle button in its title bar) and is designed for a desktop window of 1200 px or wider.

Recommendation

  • All platforms equal: A with C's density. shadcn/ui on a compact spacing scale, square thumbnails, and C's monospaced data column in the inspector. Keeps the proven stack and agent fluency, fixes A's looseness and sameness.
  • Windows first, others best-effort: B with Fluent UI React v9, accepting a plainer fallback theme on macOS and Linux.
  • You are the primary user and want a Blender- or Lightroom-like instrument: C, as a small custom design system on headless primitives.
  • A wide, less technical audience is the goal: D with Mantine.
