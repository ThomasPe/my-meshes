Privacy policy

Applies to the Meshkeep desktop app and the website meshkeep.app · Last updated 26 October 2026

In short

Meshkeep runs entirely on your device. It does not collect, store or transmit personal data, usage data or the contents of your files. There is no account, no telemetry and no advertising. Two optional features contact other services, and only when you turn them on and use them: AI assistance with your own API key, and loading a model's web page. Both are described below.

The app

  • Your files stay where they are. Meshkeep reads the folders you choose through the system dialog and keeps an index, rendered previews and your favorites and collections in the app's own data folder on your computer (%APPDATA%\de.devsym.meshkeep on Windows). Metadata you enter is written as a project.yaml file next to your models, only when you edit it.
  • Updates. The Microsoft Store version does not check for updates itself; the Store delivers them. Builds distributed outside the Store can check for updates on request, or once on startup for the development channel. That check downloads a small file from GitHub (github.com), which means GitHub sees your IP address as with any web request. GitHub's handling of that data is described in the GitHub General Privacy Statement.
  • AI assistance (optional, off until you store a key). You can ask the app to suggest metadata for a project. This only works after you enter an API key for a provider of your choice (Anthropic by default, or any service with a compatible endpoint, including one on your own machine). When you click the suggestion button for a project, the app sends that project's title, folder name and path inside your library, its file names, its existing tags and metadata, excerpts of readme-like text files in its folder, and the list of tags used in your library to that provider, which processes them under its own terms and privacy policy (for Anthropic: anthropic.com/privacy). Nothing is sent automatically, and nothing is written until you accept a suggestion. Your key is kept in the operating system's credential store and never leaves your computer except in the requests to that provider.
  • Loading model pages (optional, off by default). With the setting "Load model pages" turned on, the app can, when you ask, open the web page stored as a project's source link (for example on printables.com or thingiverse.com) to read the model's creator, license and tags and offer them as suggestions. That site sees your IP address and the address of the page, as if you had opened it in a browser; nothing else is sent, and the app sends nothing to us. The setting is off until you turn it on.
  • No other connections. Apart from the three cases above, the app makes no network requests.
  • Logs. The app writes a technical log file into its data folder to help diagnose problems. It never leaves your computer unless you attach it to a bug report yourself.
  • Deleting. Uninstalling the app and removing its data folder deletes everything it created except the project.yaml files you chose to write into your library.

The website

meshkeep.app is a static site hosted on GitHub Pages. It sets no cookies, uses no analytics and loads no fonts or scripts from third parties. GitHub, as the hosting provider, may process technical data such as your IP address in server logs to deliver the site; see the GitHub General Privacy Statement. Links to GitHub (source code, downloads, issues) lead to a third-party site with its own policy.

Your rights

Because Meshkeep processes no personal data of yours, there is nothing to export, correct or delete on our side. If you have questions about this policy, contact the publisher listed in the imprint.

Changes

If the app ever adds a feature that involves a network service, this policy and the app's settings will say so explicitly before the feature is enabled.
