Datenschutzerklärung

Gilt für die Desktop-App Meshkeep und die Website meshkeep.app · Stand 19. Oktober 2026

Kurz gesagt

Meshkeep läuft vollständig auf deinem Gerät. Die App sammelt, speichert und überträgt keine personenbezogenen Daten, Nutzungsdaten oder Dateiinhalte. Es gibt kein Konto, keine Telemetrie und keine Werbung.

Die App

  • Deine Dateien bleiben, wo sie sind. Meshkeep liest die Ordner, die du über den Systemdialog auswählst, und hält Index, gerenderte Vorschauen sowie Favoriten und Sammlungen im eigenen Datenordner der App auf deinem Rechner (%APPDATA%\de.devsym.meshkeep unter Windows). Metadaten, die du eingibst, werden als project.yaml neben deinen Modellen gespeichert, und zwar erst, wenn du etwas änderst.
  • Netzwerk. Die Microsoft-Store-Version baut keine Netzwerkverbindungen auf; Updates liefert der Store. Außerhalb des Stores verteilte Versionen können auf Anfrage nach Updates suchen, im Entwicklungskanal einmal beim Start. Dabei wird eine kleine Datei von GitHub (github.com) geladen, wodurch GitHub wie bei jedem Webabruf deine IP-Adresse sieht. Wie GitHub damit umgeht, beschreibt die GitHub General Privacy Statement. Weitere Verbindungen gibt es nicht.
  • Protokolle. Die App schreibt eine technische Logdatei in ihren Datenordner, um Probleme nachvollziehen zu können. Sie verlässt deinen Rechner nur, wenn du sie selbst einem Fehlerbericht beifügst.
  • Löschen. Deinstallation und Entfernen des Datenordners löschen alles, was die App angelegt hat, mit Ausnahme der project.yaml-Dateien, die du bewusst in deine Bibliothek hast schreiben lassen.

Die Website

meshkeep.app ist eine statische Seite, gehostet auf GitHub Pages. Sie setzt keine Cookies, nutzt keine Analyse-Dienste und lädt keine Schriften oder Skripte von Dritten. GitHub als Hosting-Anbieter kann zur Auslieferung technische Daten wie deine IP-Adresse in Serverprotokollen verarbeiten; siehe die GitHub General Privacy Statement. Links zu GitHub (Quellcode, Downloads, Issues) führen auf eine Seite Dritter mit eigener Datenschutzerklärung.

Deine Rechte

Da Meshkeep keine personenbezogenen Daten von dir verarbeitet, gibt es auf unserer Seite nichts zu exportieren, zu berichtigen oder zu löschen. Bei Fragen zu dieser Erklärung wende dich an den im Impressum genannten Verantwortlichen.

Änderungen

Sollte die App jemals eine Funktion bekommen, die einen Netzwerkdienst nutzt, weisen diese Erklärung und die Einstellungen der App ausdrücklich darauf hin, bevor die Funktion aktiv wird.
