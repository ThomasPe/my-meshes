Support

Fragen, Fehler und Ideen werden offen auf GitHub behandelt.

Problem melden

Eröffne ein Issue unter github.com/ThomasPe/my-meshes/issues. Bitte nenne die App-Version (Einstellungen → Über), deine Windows-Version und, falls relevant, die Logdatei aus dem Datenordner, der unter Einstellungen → Über steht.

Häufige Fragen

Wo speichert Meshkeep seine Daten?

Index, Vorschauen, Favoriten und Sammlungen liegen im Datenordner der App (zu sehen unter Einstellungen → Über). Deine Modelle werden nie verschoben. Eingegebene Metadaten landen als project.yaml neben den Modellen.

Vorschauen fehlen oder sind veraltet.

Einstellungen → Vorschauen → Cache leeren baut sie neu auf. Vorschauen brauchen einen funktionierenden Grafiktreiber; ohne zeigt die App Platzhalter und sagt das in der Statusleiste.

Ein Ordner auf meinem NAS aktualisiert sich nicht.

Netzlaufwerke lassen sich oft nicht auf Änderungen überwachen. Stell den Ordner in den Einstellungen auf Poll und wähle ein Intervall, oder nutze "Neu scannen".

Warum warnt Windows bei der Installation des Dev-Builds?

Dev-Builds sind nicht code-signiert, deshalb zeigt SmartScreen einmal eine Warnung. Updates, die die App selbst lädt, werden vor der Installation per Signatur geprüft.

Gibt es Meshkeep für macOS oder Linux?

Windows zuerst. macOS ist geplant; Linux ist für Version 1 kein Ziel.
