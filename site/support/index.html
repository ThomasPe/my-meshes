Support

Questions, bugs and ideas are handled in the open on GitHub.

Report a problem

Open an issue at github.com/ThomasPe/my-meshes/issues. Please include the app version (Settings → About), your Windows version and, if relevant, the log file from the data folder shown under Settings → About.

Frequently asked

Where does Meshkeep keep its data?

Index, previews, favorites and collections live in the app's data folder (shown in Settings → About). Your models are never moved. Metadata you enter is saved as project.yaml next to the models.

Previews are missing or outdated.

Settings → Previews → Clear cache rebuilds them. Previews need a working GPU driver; without one the app shows placeholders and says so in the status bar.

A folder on my NAS does not update.

Network shares often cannot be watched for changes. Switch the folder to Poll in Settings and pick an interval, or use Rescan.

Why does Windows warn when installing the dev build?

Dev builds are not code-signed, so SmartScreen shows a warning once. Updates fetched by the app are verified with a signature before they are installed.

Can I use Meshkeep on macOS or Linux?

Windows first. macOS is planned; Linux is not a target for version 1.
